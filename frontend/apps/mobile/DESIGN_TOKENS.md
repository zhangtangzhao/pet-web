# P0 间距 Token

## 主档规则

- 4px 主档：`4 / 8 / 12 / 16 / 20 / 24 / 32px`。
- 2px 是唯一允许的半档：仅用于图标与文字组合、胶囊内部、线型指示器等控件内部细密层级。
- 2px 不得用于页面留白、卡片外距、表单分组、操作栏节奏或列表项间距。
- 触控区按 `44px` 最小高度执行；高度不是空间节奏，允许单独取 `44px`。

## CSS Token

```css
:root {
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 20px;
  --space-6: 24px;
  --space-8: 32px;
  --space-half: 2px;
}
```

## 本批归档范围

- 首页商品卡。
- 宠物列表卡与列表节奏。
- 详情信息卡、SKU 卡、评价列表节奏、底部操作栏。
- 购物车商品列表与底部操作栏。
- 结算表单、优惠券列表与底部操作栏。
- 订单信息卡、信息行、操作按钮与返回栏。

## 允许保留

- 未纳入本批的历史页面和第三方组件。
- 圆角、边框宽度、字阶和行高；这些不是间距主档。
- 只影响视觉微调且不在上述归档范围内的历史小标签。
